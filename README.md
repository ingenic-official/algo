# Algo

**AI algorithm team of Ingenic Semiconductor.**

Algo team focuses on AI algorithm models and toolchains for Ingenic SoCs, widely used in smart video, biometric recognition, and edge AI.

## 技术栈 / Tech Stack

- **Models**：AI algorithm models，算法模型库
- **Tools**：AI algorithm toolchain，算法工具链
